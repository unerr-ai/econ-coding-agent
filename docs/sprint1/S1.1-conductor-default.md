**Priority chain** (first non-undefined wins):
1. `session.model` — per-session override (user picked a different model)
2. active agent's `model` ref — conductor's `openrouter/qwen/qwen3-coder`
3. `catalog.model.default()` — site-wide `model:` key in opencode.json
4. first supported available catalog model — last-resort fallback

## Credential gap

A live run requires:
- `OPENROUTER_API_KEY` environment variable set to a valid OpenRouter API key.
- The model `qwen/qwen3-coder` must be available on the OpenRouter account.

Without this key, `SessionRunnerModel.locationLayer` will find the conductor model
in the catalog (from the `providers.openrouter` block) but `Auth.config("OPENROUTER_API_KEY")`
will fail at request time when the LLM call is made. The unit test in
`session-runner-model.test.ts` does not make a live call and passes without the key.

To swap the model: update `agents.conductor.model` in `opencode.json`
to any `openrouter/<provider>/<model>` string or any other supported provider
(e.g. `anthropic/claude-sonnet-4-5` for a live Anthropic key).
