# S3.3 — Verifier Abstention Signal

## Goal

When the cheap conductor is unsure about its own answer — even on a structurally
low-risk turn — the system must escalate to the oracle rather than serving a
low-confidence answer.  This is the **verifier abstention** signal: the conductor
voluntarily opts out so the oracle takes over.

---

## Abstention contract — what the conductor must emit

The conductor (cheap model) signals abstention by including **any one** of the
following in its turn result (`ConductorResult`):

| Signal | Field | Condition |
|--------|-------|-----------|
| Structured flag | `abstain: true` | Explicit boolean; highest priority |
| Sentinel token | `text` containing `[[ABSTAIN]]` or `[[UNSURE]]` | Case-insensitive on the token name; brackets required |
| Low confidence | `confidence: number` in \[0, 1\] | Strictly below `CONFIDENCE_THRESHOLD` (default **0.5**) |

Any one signal is sufficient.  A missing field is never treated as abstention —
the check is opt-in from the conductor side.  The three signals are checked in
order; the first match wins.

### Example conductor outputs

```typescript
// 1. Explicit flag
{ abstain: true }

// 2. Sentinel token in text
{ text: "I cannot determine the correct edit here. [[ABSTAIN]]" }

// 3. Low-confidence numeric field
{ confidence: 0.3 }

// 4. Combined (flag wins first)
{ abstain: true, confidence: 0.2, text: "Not sure. [[UNSURE]]" }
```

## How it routes through routeTurn's forceTier hook

```
ConductorResult
      │
      ▼
detectAbstention(conductorResult)
      │  → AbstentionResult { abstained, confidence?, reason? }
      ▼
escalationFromAbstention(abstention)
      │  → { forceTier?: "oracle" }
      ▼
routeTurn({ risk, state, forceTier })
      │
      ├─ forceTier="oracle" present → tier="oracle"  (bypasses risk bands)
      └─ forceTier absent           → normal hysteresis logic
```

The key hook is `routeTurn`'s `forceTier` field (already implemented in S3.2).
When `forceTier` is set, `routeTurn` returns immediately with that tier — risk
score, hysteresis state, and the `abstain` flag are all ignored.

**No change to `router.ts` is required.** The abstention module is a thin
pre-processing layer that translates conductor signals into the `forceTier` value
the router already understands.

---

## Module API

**Location:** `packages/code-intelligence/src/abstention.ts`

```typescript
// Detect whether the conductor signalled unsure.
detectAbstention(conductorResult: ConductorResult): AbstentionResult

// Translate the result into a routeTurn hook value.
escalationFromAbstention(abstention: AbstentionResult): { forceTier?: "oracle" }

// Types
interface ConductorResult {
  text?:      string   // scanned for [[ABSTAIN]] / [[UNSURE]]
  confidence?: number  // [0, 1]; < CONFIDENCE_THRESHOLD → abstain
  abstain?:   boolean  // explicit flag
}

interface AbstentionResult {
  abstained:   boolean
  confidence?: number
  reason?:     string
}

const CONFIDENCE_THRESHOLD = 0.5   // configurable by importing module
```

---

## Caller integration pattern

```typescript
import { detectAbstention, escalationFromAbstention } from "./abstention.js"
import { routeTurn } from "./router.js"

// After the conductor produces a result:
const abstention = detectAbstention(conductorResult)
const { forceTier } = escalationFromAbstention(abstention)

const routing = routeTurn({ risk, state, forceTier })
// routing.tier is "oracle" if conductor abstained, else risk-band logic applies.
```

## Design decisions

- **No router.ts change:** the `forceTier` hook added in S3.2 already covers
  the bypass path.  Abstention is purely a pre-processing step.
- **Three signals, any one sufficient:** different model families expose
  different confidence interfaces.  Supporting all three means the conductor
  integration is not tied to a specific output format.
- **Threshold default 0.5:** chosen as a conservative mid-point.  Below 50 %
  confidence the conductor is effectively guessing; the oracle should take over.
  Callers may import `CONFIDENCE_THRESHOLD` and compare against it if they need
  to apply a different threshold in their own logic.
- **Opt-in signals only:** the absence of a confidence field is never treated as
  abstention, so existing conductor integrations that don't emit confidence are
  unaffected.
