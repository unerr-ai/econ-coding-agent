# S3.7 — Reasoner Mode (Three-Rung Ladder)

## Goal

Add a **reasoner** tier — a mid-size thinking model (chain-of-thought) — between the cheap
conductor and the expensive oracle. CoT is paid **only on explicitly flagged hard steps**, never
as a default tax on every turn.

---

## Three-Rung Ladder

```
conductor (cheap, no CoT)
    │  hardStep=true
    ▼
reasoner (mid, CoT — thinking model)
    │  alreadyTriedReasoner=true  OR  risk > 70
    ▼
oracle   (frontier, large model)
```

| Tier | When selected | CoT paid? |
|------|--------------|-----------|
| conductor | `hardStep` absent/false, risk ≤ escalateAbove | No |
| reasoner  | `hardStep=true`, `alreadyTriedReasoner=false`, risk ≤ escalateAbove | Yes (mid cost) |
| oracle    | risk > escalateAbove **or** (`hardStep=true` and `alreadyTriedReasoner=true`) | Yes (high cost) |

Risk-band hysteresis (conductor ↔ oracle, thresholds 40/70) is unchanged — the reasoner
tier is layered **on top** via the explicit `hardStep` signal, so normal turns never change
routing behaviour.

---

## Hard-Step Signal Contract

The conductor (or any caller) sets `hardStep: true` on a `RouterInput` when the current
step requires structured reasoning. The signal is **step-local** — it must be explicitly
passed each call; it is never inferred from history.

```typescript
// packages/code-intelligence/src/router.ts
routeTurn({
  risk,
  state,
  hardStep: true,             // this step needs CoT
  alreadyTriedReasoner: false // first attempt
})
// → { tier: "reasoner", ... }

routeTurn({
  risk,
  state,
  hardStep: true,
  alreadyTriedReasoner: true  // reasoner already tried, still hard
})
// → { tier: "oracle", ... }
```

The dedicated pure function in `reasoner.ts` encodes the same contract and can be
called independently of `routeTurn` when step-level routing is needed:

```typescript
// packages/code-intelligence/src/reasoner.ts
decideReasoner({ risk, hardStep, alreadyTriedReasoner })
// → { tier: "conductor" | "reasoner" | "oracle", reason: string }
```

---

## Hysteresis Safety

A "reasoner" tier in `RouterState` **de-escalates to conductor** on the next mid-band
turn that carries no `hardStep` signal. This ensures CoT is not accidentally inherited
across turns:

```
turn N:   hardStep=true  → reasoner  (state.tier = "reasoner")
turn N+1: hardStep unset → conductor (mid-band: reasoner → conductor mapping)
```

No conductor ↔ reasoner flapping: reasoner is entered only on an explicit signal, never
by crossing a risk band.
