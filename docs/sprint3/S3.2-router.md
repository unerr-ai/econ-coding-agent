# S3.2 — Risk-Escalation Router

## Goal

Fork model resolution into a **risk-escalation router** so that high-risk turns are
automatically escalated to the oracle tier and low-risk turns stay on the cheap
conductor, with **hysteresis** to prevent mid-band flapping.

---

## Hysteresis state machine

```
         risk > 70
    ┌──────────────────────────────►  oracle
    │                                  │
    │                    risk < 40     │
    │  ◄────────────────────────────────┘
 conductor
    │
    │  40 ≤ risk ≤ 70 → HOLD (no-flap zone)
    └─────────────────────────────────────►  (stay in current tier)
```

| Band | Default threshold | Action |
|------|------------------|--------|
| High  | risk > 70        | Escalate to oracle |
| Low   | risk < 40        | De-escalate to conductor |
| Mid   | 40 ≤ risk ≤ 70   | Hold current tier (no flap) |

Both thresholds are configurable via `RouterLayerConfig.routerConfig`.

---

## Pure router

**Location:** `packages/code-intelligence/src/router.ts`

```typescript
routeTurn(input: RouterInput, config?: RouterConfig): RouterOutput

RouterInput {
  risk: number         // 0–100 from S3.1 computeTurnRisk
  state: RouterState   // previous tier (hysteresis carrier)
  abstain?: boolean    // S3.3 hook: hold tier without transition
  forceTier?: Tier     // S3.5 hook: bypass risk logic entirely
}

RouterOutput {
  tier: "conductor" | "oracle"
  reason: string       // human-readable routing explanation
  state: RouterState   // updated state — callers must persist this
}
```

Evaluation order:
1. `forceTier` (S3.5 triage) — immediate return, skips everything else
2. `abstain` (S3.3) — hold without recording a transition
3. `risk > escalateAbove` → oracle
4. `risk < deescalateBelow` → conductor
5. mid-band → hold current tier

## Fork point

**File:** `packages/core/src/session/runner/model.ts`

**Added:** `locationLayerWith(config: RouterLayerConfig)` — the fork.  
**Changed:** `locationLayer` is now `locationLayerWith({})` (degrade-open default).

The fork is at the top of the `resolve` function body inside `locationLayerWith`, before the existing S1.1 chain runs:

```typescript
// packages/core/src/session/runner/model.ts — inside locationLayerWith closure
let routedAgentModel = undefined
if (!session.model) {                           // explicit overrides always win
  const risk = yield* riskProvider(session)    // injected; defaults to 0
  const prevState = routerStateMap.get(session.id) ?? defaultRouterState
  const { tier, state: nextState } = routeTurn({ risk, state: prevState }, routerCfg)
  routerStateMap.set(session.id, nextState)
  routedAgentModel = (yield* agents.resolve(AgentV2.ID.make(tier)))?.model
}

// S1.1 chain (preserved as fallback):
const agentModel = session.model
  ? undefined
  : routedAgentModel ?? (yield* agents.resolve(session.agent))?.model
```

## Degrade-open behavior

The system **never crashes** when no risk signal is available:

| Scenario | Behavior |
|----------|----------|
| No `riskProvider` injected | Default provider returns 0 → conductor always selected |
| `riskProvider` injected but returns 0 | Same: conductor |
| Tier agent not configured in opencode.json | `agents.resolve(tier)` returns `undefined` → falls through to S1.1 agent-model chain |
| Oracle agent in config but no model | `tierAgent?.model` is `undefined` → falls through |

Restarting the process resets hysteresis state to `{ tier: "conductor" }` — cost-safe.

---

## Hysteresis state persistence

State is kept in an **in-memory `Map<sessionID, RouterState>`** inside the
`locationLayerWith` closure, created once per layer instance.

**Rationale for in-memory over S1.3 SQLite canonical-state:**

- Router state is *transient* — a restart defaulting to conductor is cost-safe
  (we might run one extra mid-tier turn, not a costly oracle turn)
- No migration, no I/O on every turn
- Simple and provably correct for the hysteresis guarantee

**If cross-restart persistence is ever needed** (e.g. a long-running session that
restarted mid-turn), wire into S1.3 `SessionCanonicalState.setScratchpad` with
key `"router.tier"` at the `routerStateMap.set` site. No interface changes needed.

## Tier → model mapping

Configured in `opencode.json` `agents` block:

| Tier | Agent ID | Model | Sprint |
|------|----------|-------|--------|
| conductor | `conductor` | `openrouter/qwen/qwen3-coder` | S1.1 |
| oracle | `oracle` | `openrouter/deepseek/deepseek-r1` | S3.2 |

Adding more tiers later is purely a config change (new agent entry).

## Extension hooks for later sprints

Both hooks are already wired into the `RouterInput` shape — no signature change needed:

| Hook | Sprint | Input field | Behavior when set |
|------|--------|-------------|-------------------|
| Abstention | S3.3 | `abstain: true` | Hold current tier, skip risk evaluation |
| Triage override | S3.5 | `forceTier: "oracle"\|"conductor"` | Bypass risk logic entirely |

To activate from `locationLayerWith`, the caller can wrap the `riskProvider` to also
return an `abstain` flag, or the router call site can accept an additional input builder.
The pure `routeTurn` function already handles both; only the call site in `model.ts` needs
to pass the extra fields.
