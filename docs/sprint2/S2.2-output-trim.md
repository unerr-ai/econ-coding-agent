# S2.2 — Tool Output Trimming

## What was ported

Two modules were ported from `../unerr-cli/src/intelligence/`:

| Source | Ported into |
|---|---|
| `token-estimator.ts` — `detectContentType` + `estimateTokenCount` | `packages/code-intelligence/src/trim.ts` → `estimateTokens()` |
| `smart-truncate.ts` — structural-priority truncation | `packages/code-intelligence/src/trim.ts` → `smartTruncate()` |

**Adaptation note.** The original `smartTruncate` operates on structured entity sections
(metadata / imports / signatures / bodies). This port targets flat tool output (bash stdout,
file reads), so the input is a plain `string` and the strategy is **head + match-context +
tail** rather than structural priority. The token-estimator heuristic is carried over
unchanged: content-type detection + whitespace-discounted char ratio.

No external dependencies were introduced — the gpt-tokenizer import in the original
`token-estimator.ts` was intentionally omitted. The heuristic fallback is sufficient for a
budget guardrail (accuracy ±10–20%).

## Trim policy

```
Budget:  4000 estimated tokens  (plugin constant OUTPUT_BUDGET)
Head:    40% of budget          (preamble, imports, command header)
Middle:  30% of budget          (query match context when query supplied)
Tail:    30% of budget          (result, exports, exit status)
Margin:  100-char reserve for the elision marker line
```

Elision marker format:
```
... [N lines elided — T estimated tokens, budget B] ...
```

The marker embeds the full estimated token count (`T`) so the model can decide whether
the missing content is worth a targeted follow-up.

## Hook wiring

Plugin file: `.opencode/plugins/econ-output-trim.js`

Hook used: `tool.execute.after` — confirmed present in
`packages/plugin/src/index.ts` (line 274) with signature:

```ts
"tool.execute.after"?: (
  input: { tool: string; sessionID: string; callID: string; args: any },
  output: { title: string; output: string; metadata: any },
) => Promise<void>
```

The plugin mutates `output.output` in place (same pattern as the `.before` hook mutates
`output.args` in `econ-gate-spike.js`).

Targeted tools:
| Tool ID | Source file |
|---|---|
| `bash`  | `packages/opencode/src/tool/shell/id.ts` — `ToolID = "bash"` |
| `read`  | `packages/opencode/src/tool/read.ts` |
| `grep`  | `packages/opencode/src/tool/grep.ts` |
| `glob`  | `packages/opencode/src/tool/glob.ts` |

`write`, `edit`, `apply_patch` are intentionally excluded — their outputs are short
confirmations, not potentially large text blobs.
